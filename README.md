# Flight Delay Prediction (Phase 1: ML)

Predict whether a flight departing from New York will arrive 15 or more minutes late, using information available by the end of the previous day. The project also explores alternative departure times through an offline what-if rescheduling analysis.

Course project for **Advanced Machine Learning — Project 21 (Flight Delay Prediction and Rescheduling)**.

Phase 1 focuses on the classical ML pipeline: EDA, feature engineering, Logistic Regression, XGBoost, probability calibration, and rescheduling analysis.

## Dataset & Setup

- **Dataset:** Kaggle Flights dataset (based on `nycflights13`)
- **Size:** 336,776 departures from EWR, JFK, and LGA during 2013
- **Data location:** `data_raw/flights.csv`
- **Target:** `arr_delay >= 15` minutes, following the BTS delay definition

Cancelled and diverted flights are excluded from labeled examples but remain included in scheduled-volume features.

## Experimental Setup

- **Decision time:** End of the previous day. Features use published schedules and outcomes from strictly earlier dates.
- **Leakage prevention:** Notebook 02 includes a leakage test to verify the past-only feature construction.
- **Chronological split:**
  - Train: January–September
  - Validation: October–November
  - Test: December

All model settings, calibration methods, rolling windows, and thresholds are selected using validation data. December is reserved for final evaluation.

## Model Performance

**December test results**

| Model | PR-AUC | ROC-AUC | Brier | ECE |
|---|---:|---:|---:|---:|
| Prior rate (constant) | 0.335 | 0.500 | 0.230 | 0.086 |
| Route history baseline | 0.381 | 0.554 | 0.230 | 0.095 |
| Logistic Regression | 0.461 | 0.640 | 0.222 | 0.103 |
| XGBoost | 0.468 | 0.645 | 0.221 | 0.102 |

## Key Findings

- On validation, Logistic Regression performs slightly better than XGBoost (PR-AUC: 0.297 vs 0.276).
- XGBoost becomes competitive with very large leaves (`min_child_weight=2000`). Otherwise, it tends to memorize individual training days through day-level history features.
- December has the highest delay rate at 33.5%, compared with 17.8% across October and November.
- A Platt calibrator fitted on October–November under-predicts December delays. For XGBoost, ECE increases from 0.073 to 0.102, while rolling Platt recalibration over the previous 28 days reduces it to 0.047.
- A threshold selected on validation for precision of at least 0.5 achieves 0.66 precision on the December test set, but recall remains low at 0.035.
- In the rescheduling analysis, 133 out of 1,979 flights with predicted risk of at least 0.5 have an alternative departure time within ±2 hours that reduces predicted risk by at least 0.05. Most beneficial moves are earlier departures.

## How to Run

**Requirements:** Python 3.11

Install the dependencies:

```bash
pip install -r requirements.txt
```

Place the dataset at `data_raw/flights.csv`, then open Jupyter and run notebooks 01–05 from top to bottom.

The complete workflow takes approximately 1.5 minutes on a laptop.

To rebuild the report PDF, run the following inside the `report/` directory:

```bash
latexmk -pdf main.tex
```

## Limitations

- Weather forecasts are unavailable, even though day-level weather explains much of the variation in delays.
- The dataset covers only one year of departures from three New York airports.
- Inbound flights and aircraft rotation information are not available.
- The rescheduling analysis is associational and does not account for crew availability, aircraft rotations, or passenger connections.
